Clique nos estados que você acompanha — o arquivo baixa direto do site da Caixa. Depois arraste os arquivos baixados para a pasta fontes e rode scripts\atualizar.ps1 (botão direito → Executar com o PowerShell). O site se atualiza sozinho em seguida.

3. Link direto para a matrícula (RGI)

A Caixa publica a matrícula de cada imóvel num endereço previsível, com o número do imóvel dentro. Cole abaixo o endereço de uma matrícula que você já tenha baixado — a plataforma descobre o padrão sozinha e passa a gerar o link direto para todos os imóveis, sem você precisar abrir a página de cada um.

Para achar o endereço: no Chrome, tecle Ctrl+J para abrir os downloads. Embaixo do arquivo da matrícula aparece o site de origem — clique com o botão direito nele e escolha "Copiar endereço do link".

4. Link para o LEMIT (opcional)

Coloca um botão Consultar no LEMIT na ficha de cada imóvel. É só navegação: abre a plataforma que você assina, com o endereço do imóvel no endereço da consulta. Nada é buscado nem trazido de volta para cá — a consulta é sua, feita no seu acesso e sob sua responsabilidade.

Cole abaixo o endereço de uma busca que você já tenha feito lá. Onde aparecer o endereço do imóvel, escreva {endereco}; se a URL usar a UF, escreva {uf}. Exemplo:
https://app.lemit.com.br/busca?q={endereco}

Atenção: o navegador bloqueou o armazenamento local nesta página. Os dados existem apenas enquanto a aba estiver aberta. Faça o backup antes de fechar, ou abra a plataforma pelo servidor local (npm start).

Sincronização online (GitHub)

Guarda o seu trabalho — etapas, anotações, fichas de ocupante e de arrematador, marcações de lido — num repositório privado do GitHub. Assim você abre a plataforma em qualquer máquina, importa o CSV do estado que interessa, e suas anotações aparecem em cima dos imóveis.

A listagem da Caixa não é sincronizada de propósito: ela tem megabytes e você rebaixa em um clique. O que sincroniza é o que não dá para refazer.

Sobre o token: ele dá acesso de escrita ao repositório e fica guardado neste navegador. Crie um token fine-grained limitado a um único repositório, com permissão apenas de Contents: Read and write. Nunca use um token clássico com acesso amplo.

Backup completo

Os dados ficam salvos no armazenamento local deste navegador, neste computador. Limpar o histórico do navegador apaga tudo. Exporte um backup com frequência — é o seu único arquivo recuperável.

Ambiente de teste

Cria uma base fictícia grande — dezenas de imóveis em vários estados, com datas, etapas, ocupantes e arrematadores variados — para você experimentar mudanças, filtros e ordenações sem tocar nos dados reais.

Isto é um interruptor, não um botão de carga. Ao entrar em modo de teste, seus dados reais são guardados de lado e a tela passa a mostrar só o fictício — com uma tarja no topo para você não confundir. Ao sair, o fictício é descartado e os dados reais voltam exatamente como estavam.
